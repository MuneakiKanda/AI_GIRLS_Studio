# 技術・データ・ガバナンスの方針候補

AI GIRLS Studio 構想整理 v0.1 / 2026年11月4日

以下は技術構成の候補であり、採用済みの実装仕様ではありません。

## 想定する推論経路

1. **プレイヤーのPC**：ゲーム本体、会話履歴、ゲーム状態をローカルに保存し、必要な推論リクエストを送る。
2. **Studio管理のAIゲートウェイ**：認証、利用枠、予算制御、レート制限、安全制御を扱う。
3. **外部LLMプロバイダー**：推論処理を提供する。

ユーザー自身のAPIキーを必須にしない利用体験を想定した候補です。実際の提供主体、プロバイダー、モデル、技術スタック、運用方法は未決定です。

## 保存と通信を分けて考える

会話履歴やゲーム状態をユーザー側に保存することは、アーキテクチャの方針候補です。ローカル保存であっても、外部推論に必要な情報は通信で送信されます。完全オフライン動作や、データが一切端末外に出ないことを意味しません。

送信する情報の範囲、通信時のプライバシー、ゲートウェイや外部プロバイダー側のログ・保持、運営責任、障害時の扱いは別途検討が必要です。保存形式、バックアップ、移行、削除も未決定です。

AI Memory Archiveには記憶や意思決定の経緯を長期保存・再利用する構想がありますが、このゲームの保存機構として採用・統合することは決めていません。

## 判断と実行権限

AIの提案と人間の最終判断を区別し、人格設定とシステム上の実行権限を分離することを原則とします。ゲーム内の自律性や、制作支援AIに与える操作権限の具体的な範囲は未確定です。

予算制御や安全制御はゲートウェイの想定機能であり、安全性や費用上限がすでに検証されたことを意味しません。関連する未決事項は[open-questions.md](open-questions.md)を参照してください。
