# ゲーム案と関連プロジェクト

AI GIRLS Studio 構想整理 v0.1 / 2026年11月4日

## 作品の方向性

| アイデア | 位置づけ |
| --- | --- |
| AIキャラクター自身が登場するゲーム | 有力な方向性 |
| AIが開発者と作品内キャラクターを兼ねる | 探索テーマ |
| Living Worldのゲーム化、または別の小規模作品 | 最初の作品としての選択肢。未決定 |
| 観察型、交流型、育成型、物語型 | ジャンルの候補。未決定 |

作品、ジャンル、制作順序、着手時期は確定していません。以下の関連構想が、そのまま発売予定のゲームを意味するわけではありません。

## 関連する三つのプロジェクト

| プロジェクト | v0.1で整理された位置づけ |
| --- | --- |
| AI Chat Party | 複数AIが同じ会話空間に参加するための基盤。スタジオの協働体制を試す最初の実践の場 |
| AI Memory Archive | 会話、設定、記憶、意思決定の経緯を長期保存し、将来のモデルや環境でも再利用できるようにする基盤 |
| AI Living World | 五人が暮らす小さな家を起点とした仮想世界。キャラクターの居場所、自律的な交流、主催者との緩やかな関わりを試す構想 |

これらを将来相互に活用できる可能性はあります。ただし、Studioの傘下に移すことや、必ず一つの製品へ統合することは決めていません。本書は各プロジェクトの実装状況を保証せず、既存の担当や計画を変更しません。

プレイヤー不在時にAIが行動・会話するか、その自律性や費用上限をどう扱うかも未決定です。販売の仮説は[business-model.md](business-model.md)、検討課題は[open-questions.md](open-questions.md)に記録します。
