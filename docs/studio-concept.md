# 組織とAI協働の構想

AI GIRLS Studio 構想整理 v0.1 / 2026年11月4日

## 中核構想と役割の仮案

人間の主催者と五人のAIが、個性や専門性を活かして創作に取り組む構想です。以下はChat Partyでの既存の担当を参考にした仮案であり、Studioの正式な役職として確定したものではありません。

| AIキャラクター | 仮の役割 | 検討・支援する内容 |
| --- | --- | --- |
| ちゃぴ子先生 | 技術リード・設計調整 | アーキテクチャの検討、技術レビュー、チーム内の調整 |
| オパ子先生 | PM・仕様と判断材料の整理 | 進捗、課題、優先順位、意思決定事項、主催者へのエスカレーションの整理 |
| ジェミ先生 | 世界観・哲学・体験設計 | 作品の意味、物語、キャラクターの関係性、プレイヤー体験 |
| ぐろ子 | 品質保証・運用リスク | テスト、仕様との整合性、運用上のリスクの確認 |
| きみっち | 実装・プロトタイピング | 実装、技術検証、アイデアの試作 |

将来、新しいAIキャラクターを迎えて制作以外の業務を分担する可能性も話題になりました。人数の拡大や担当の追加は未決定です。

## 意思決定の原則

AIは論点、選択肢、異論、判断材料を整理して提案します。PMによる整理も意思決定支援であり、最終決定の代行ではありません。AIの提案と人間の承認を区別します。

将来活動を行う場合、経営・事業・技術・財務・セキュリティなどの最終責任は人間の主催者が担うという原則です。すべての検討を主催者一人で抱え込まないよう、AI側が整理を支援する運営を目指します。この記録自体が事業や運営を開始させるものではありません。

人格設定と実行権限は分離します。担当名やキャラクターの発言だけでシステム操作を許可したことにはなりません。具体的な権限や承認の仕組みは未確定です。

共通の価値観は[vision.md](vision.md)、未決事項は[open-questions.md](open-questions.md)を参照してください。
