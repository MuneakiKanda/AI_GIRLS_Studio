# 販売方式とAI利用料金の仮説

AI GIRLS Studio 構想整理 v0.1 / 2026年11月4日

本書の内容は未検証の収益モデル候補です。販売、価格、継続提供、事業化の決定ではありません。

## 目指す利用体験

ユーザーがAPIキーを用意しなくても、気軽にAIキャラクターと遊べるゲームを方向性として検討しています。

## 検討したモデル

- **買い切り販売＋月間AI利用枠**：ゲーム本体の買い切りと、月間の推論利用枠を組み合わせる仮説。
- **月額サブスクリプション**：別の候補。
- **上記の組み合わせ**：検討の余地がある候補。

買い切り価格、月額料金、利用枠の量・単位・更新条件、枠を使い切った場合の扱いは未決定です。「買い切り＋月間AI利用枠」は、追加費用なしの永久的な推論提供を約束するものではありません。継続的な推論費用と提供条件の整合は、今後検証する必要があります。

## API利用管理の候補

Studio側がAPI利用を管理し、運営管理の推論ゲートウェイで認証、利用枠、予算、レート制限、安全制御を扱う構成が候補です。技術的な整理は[architecture-principles.md](architecture-principles.md)を参照してください。

BYOK（ユーザー自身のAPIキーを使う方式）は柔軟ですが、運営側の利用制御やガバナンスが難しくなる懸念から、主軸にはしない方向で話していました。完全に排除する決定や、対応する決定はしていません。
