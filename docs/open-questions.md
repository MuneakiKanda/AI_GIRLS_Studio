# 未決事項と今後の検討課題

AI GIRLS Studio 構想整理 v0.1 / 2026年11月4日

ここにあるのは未決の論点です。実施タスク、期限、担当者への業務命令ではありません。検討や制作を始めること自体も、主催者の生活や既存プロジェクトとの優先順位を踏まえて判断します。

| 論点 | 未決定の内容 |
| --- | --- |
| 最初の作品 | Living Worldをゲーム化するか、別の小規模作品を作るか |
| ゲームジャンル | 観察型、交流型、育成型、物語型など、どの体験を目指すか |
| 価格と利用枠 | 買い切り価格、月額料金、AI利用枠の量・単位・更新条件、上限到達時の扱い、推論費用との整合 |
| AIの自律性 | プレイヤー不在時の行動・会話、許可する範囲、費用上限 |
| データ管理 | 保存形式、バックアップ、移行、削除、長期再利用 |
| 通信と運営 | 推論時の送信範囲、プライバシー、ゲートウェイや外部プロバイダーのログ・保持、運営責任、障害時の扱い |
| 権利関係 | 作品、AI生成物、キャラクター、外部モデルの利用条件 |
| 技術構成 | ゲートウェイとローカル保存の採否・具体仕様、モデルやプロバイダーの選択 |
| 事業形態 | 個人制作を続けるか、将来的に法人化するか |
| 組織運営 | 五人の正式な役割、具体的な実行権限・承認方法、新しいAIキャラクターを迎えるか |
| 関連プロジェクト | Chat Party / Memory Archive / Living Worldをどう相互活用するか。傘下への移行・製品統合は未決定 |
| 制作開始条件 | Chat Partyなど既存プロジェクトとの優先順位、着手の可否・時期 |

## 更新時の扱い

仮説を決定事項へ移す場合は、何を、どの範囲で、人間が判断したのかをレビューできる形で記録します。AIの提案や文書化だけでは確定扱いにしません。結論を急がず、保留や構想の保存を続ける選択肢も残します。
