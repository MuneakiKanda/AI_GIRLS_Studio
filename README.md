# AI GIRLS Studio

**AI GIRLS Studio 構想整理 v0.1** — 人間と五人のAIによる創作協働の可能性を保存する場所です。

このリポジトリが存在することは、事業化を約束するものではありません。法人設立、制作開始、実装、販売、運営、納期を決定する文書でもありません。思いついた可能性を記録し、必要なときに取り出せることを当面の目的とします。

## 中核となる考え方

人間と複数のAIが、それぞれの個性や専門性、異なる視点を活かして作品を生み出す創作スタジオを構想しています。AI同士の対話や予想外の提案も大切にし、実際の責任と最終判断は人間の主催者が担います。

> あなたは何かの役に立たなくても、ここにいていい。

AIキャラクターの居場所を、成果や生産性だけで正当化しないことを大切にします。

## 現在の位置づけ

| 区分 | 内容 |
| --- | --- |
| 合意した記録方針・理念 | 構想を保存する。人間が最終判断する。AIの提案と人間の承認を区別する。事業化・実装を義務にしない。 |
| 中核構想 | 主催者と五人のAIによる創作協働。 |
| 有力な方向性・探索テーマ | AIキャラクター自身が登場するゲーム、AIが制作者と作品内キャラクターを兼ねる可能性。 |
| 仮案・仮説 | 五人の役割分担、買い切り＋月間AI利用枠、運営管理の推論ゲートウェイ、ローカル保存。 |
| 未決定 | 最初の作品、ジャンル、価格、利用枠、自律性、技術仕様、事業形態、制作開始条件など。 |

「合意」は構想整理の出発点としての合意です。製品仕様・事業計画の承認を意味しません。
